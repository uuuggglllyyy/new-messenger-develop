## ✨ Особенности

*   **Функциональность чата:** Приложение включает в себя базовые возможности для обмена текстовыми сообщениями и файлами (в папке `chat`).
*   **Управление пользователями:** Реализована система аккаунтов (`accounts`) для регистрации, аутентификации и управления профилями.
*   **Система уведомлений:** Модуль `notifications` отвечает за оповещения о новых сообщениях или событиях.
*   **Минималистичный дизайн:** Интерфейс выполнен в минималистичном стиле, что обеспечивает удобство и фокус на общении.
*   **Асинхронность:** Для работы с чатами в реальном времени, вероятно, используются технологии, поддерживающие асинхронность (например, Django Channels или WebSockets).
*   **Готовность к разработке:** Структура проекта логично разделена на приложения, что упрощает добавление новых функций.

## 🛠 Технологии

*   **Backend:** Python 3, Django
*   **Frontend:** HTML5, CSS3 (вероятно, с использованием фреймворков или подходов для минималистичного дизайна)
*   **База данных:** SQLite (по умолчанию, файл `db.sqlite3` в репозитории)
*   **Инструменты:** pip (для управления зависимостями), Git

## 🚀 Установка и запуск

Следуйте этим шагам, чтобы запустить проект локально:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/uuuggglllyyy/new-messenger-develop.git
    cd new-messenger-develop
Создайте и активируйте виртуальное окружение (рекомендуется):

bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
venv\Scripts\activate   # Для Windows
Установите зависимости:

bash
pip install -r requirements.txt
Выполните миграции базы данных:

bash
python manage.py migrate
(Опционально) Очистите или наполните базу данных:

bash
python clean_chat_messages.py  # Если скрипт предназначен для очистки
# или создайте суперпользователя для доступа в админку
python manage.py createsuperuser
Запустите сервер разработки:

bash
python manage.py runserver
Откройте браузер и перейдите по адресу http://127.0.0.1:8000/.

📖 Как использовать
После запуска приложения:

Зарегистрируйтесь или войдите в существующий аккаунт через интерфейс.

Перейдите в раздел чатов, чтобы найти других пользователей или начать новый диалог.

Отправляйте текстовые сообщения и файлы.

Получайте уведомления о новых сообщениях (входящие уведомления реализованы в модуле notifications).
